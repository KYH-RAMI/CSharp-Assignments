# Prague Parking V2

Prague Parking V2 är en objektorienterad vidareutveckling av Prague Parking V1.

Projektet utvecklas i C# med .NET 10.

## Projektstruktur

- `PragueParkingV2` – huvudapplikation och konsolgränssnitt
- `PragueParkingV2.Data` – separat klassbibliotek för dataåtkomst
- `docs` – kravanalys, klassdiagram och designbeslut
- `LOGGBOK.md` – löpande dokumentation av utvecklingsarbetet

## Status

Projektet befinner sig för närvarande i planerings- och designfasen. Ingen parkeringslogik är ännu implementerad.

## Teknik

- C# / .NET 10
- Spectre.Console för konsolgränssnittet
- System.Text.Json för JSON-serialisering och deserialisering
- Git och GitHub för versionshantering
